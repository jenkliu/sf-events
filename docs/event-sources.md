# SF Event Sources — catalog for the weekly aggregator

Goal: pull the coming week's SF events into one place, filterable by category (music, arts, fitness, cultural, etc.). This lists sources ranked by how easily an automated task can ingest them, plus which categories each covers. Last reviewed: 2026-09-22. The category profiles below use the current vocabulary — see README.md's Categories section for the full list and `categorize()` in `scrape.mjs` for the keyword rules. (Superseded: "Nightlife" was folded into Music — nearly everything tagged Nightlife was already a DJ set or dance party, i.e. also Music — and the old catch-all "Community & Social" was split into Community & Social, Volunteering & Civic, Festivals & Markets, and Talks & Workshops once Civic Joy Fund's cleanups and The Commons' wellness/professional programming made it too broad to mean anything.)

## The honest architecture

There is no single API that returns "all SF events." A good aggregator blends a few structured feeds/APIs (the reliable backbone) with light scraping of a few well-structured sites (for the long tail), then normalizes, filters, dedupes and tags by category. Two things to know up front:

- Eventbrite's public event-search API was shut off in Feb 2020. You can only pull events for your own organization now, not search all public events. To get Eventbrite listings you either scrape or use a third-party scraper. Don't design around an Eventbrite "search everything" call — it no longer exists.
- Meetup's API is GraphQL and needs OAuth (and a Pro subscription for the fullest access), but it's the best structured source for fitness/social/hobby events.

## Global normalization rules (apply to every source)

- **Drop private events.** Venue calendars are full of private buyouts/holds. Exclude anything marked private: The Faight's Sanity `isPrivate == true`; Google Calendar entries titled "Private Event" (or "Private", "Buyout", "Closed"). Wave Collective's calendar alone had 9 private holds in ~6 weeks. Match on the private flag where available, and on a title regex `/(^|\b)(private|buyout|closed)\b/i` otherwise.
- **Drop past events.** Only keep events from now forward (some sources, e.g. Gather SF, leave stale past events on the page).
- **Convert times to America/Los_Angeles.** Google Calendar and Sanity return UTC.
- **Normalize to one shape:** title, start (date+time), end, venue, category[], url, price/free, source. Keep a parseable start time for sorting (sort within a day earliest→latest).
- **Dedupe on date + venue + normalized title** — sources overlap (see Lower Haight Local below).

## Tracked venues & neighborhood sources (what Jen wants monitored)

Specific venues and neighborhood feeds to pull directly, separate from the broad aggregators below. All confirmed working as of 2026-09-20 (Civic Joy Fund 2026-09-21), pulled live.

- **The Faight** — 475 Haight St, Lower Haight. Page: https://www.thefaight.com/events — A Next.js site backed by a **public Sanity CMS**, which is the real prize: query it directly instead of scraping HTML. Project `3l1powkg`, dataset `production`. Endpoint: `https://3l1powkg.apicdn.sanity.io/v2021-10-21/data/query/production?query=<GROQ>`. Working query: `*[_type=="event" && status=="published" && !isPrivate && startTime > "<now>"]|order(startTime asc){title, startTime, endTime, ctaUrl, "desc":pt::text(description), "slug":slug.current}`. Notes: filter `status=="published"` and `!isPrivate`; `ctaUrl` is the ticket link (usually Eventbrite); `startTime` is UTC. **Do not** pull the `showNotes` field — internal production notes with artist contact info. Cross-origin browser fetch is CORS-blocked; fetch server-side. Category profile: almost entirely Music (DJ/electronic nights included), plus recurring Open Mics (Community & Social).
- **Madrone Art Bar** — 500 Divisadero St, NoPa. Pulled from the venue's own calendar, which runs The Events Calendar on WordPress and publishes an iCal export: `https://madroneartbar.com/calendar/<YYYY-MM>/?ical=1`. Each export covers a single month view, so fetch one per month the window touches; the views overlap at the edges, so dedupe on `UID`. Events carry `SUMMARY`, `DESCRIPTION`, `DTSTART` (`TZID=America/Los_Angeles`, or `VALUE=DATE` for the handful posted without a time), `URL` and `LOCATION` — but no price or category fields, so cover is read off the copy (a `$n` figure vs. "no cover") and categories come from `categorize()`, falling back to Music. Gotcha: the site sits behind a bot check that serves an HTML "please wait while your request is being verified" page instead of the feed for roughly 1 request in 3, at random — retry and it clears. Category profile: genuinely mixed — Music first (DJ nights included), then Arts & Performance, Community & Social, Festivals & Markets. Mostly free or a small cover. Also listed on DoTheBay (`https://dothebay.com/venues/madrone-art-bar.json`), but that only carries the few shows someone cross-posted — 3 upcoming against 68 in the venue's own feed.
- **Wave Collective** — 663 Haight St, Lower Haight. A café/event space with a **public Google Calendar**: ID `k5bmnva5i30lo1id9kovrvjc4g@group.calendar.google.com` (name: "Wave Collective Space Events Calendar"). Ingest via **Google Calendar API v3** `events.list` with `singleEvents=true` (free API key). IMPORTANT: heavy on private bookings titled "Private Event" — filter them out (see global rules). Public events are recurring café/community programming (Coffee Hours, Coffee & Wine Hours, DJ and Wine Fridays, Poetry Circle) plus one-offs (comedy nights, art openings). Category profile: Community & Social, Music (DJ nights), Arts & Performance.
- **Lower Haight Local** — https://www.lowerhaightlocal.com/events — a volunteer neighborhood calendar (501c3, est. 2025) spanning many Lower Haight venues at once: Madrone, Woods Lowside, Danny Coyle's, Mercury Cafe, The Booksmith, Underground SF, The Faight, plus street fairs, park movie nights, and weekly cleanups. Best category coverage of anything on this list — the only source that reliably surfaces Fitness & Wellness (line dancing), Community & Social (trivia, bingo), Volunteering & Civic (the weekly Lower Haight Cleanup), and Festivals & Markets (street fairs). Public Google Calendar ID `c355b17347d2721bff62a21b8378d5caa0a717f34a4a465f13a624d85525e6d6@group.calendar.google.com` (or scrape the HTML page). NOTE: this is a DIFFERENT calendar from Wave Collective's. Overlap warning: this feed re-lists events already coming from The Faight (Open Mics) and Madrone (Game Night), so it's the clearest real dedup case in the set.
- **tiat (the intersection of art & technology)** — 151 Powell St, Union Square. Page: https://www.tiat.place/events — A 501(c)(3) art/tech gallery and experimental hub (opened Nov 2025 via the city's Vacant to Vibrant program). New media exhibitions, maker sessions, workshops (projection mapping, computational poetry, generative media), salons, occasional raves. Category profile: mostly Arts & Performance, with some Music and Talks & Workshops (maker sessions, salons) — `categorize()` falls back to Arts & Performance here. Not on DoTheBay/Do415. Events live on **Luma** (https://luma.com/tiat), pulled via Luma's unofficial public JSON endpoint: `https://api.lu.ma/calendar/get-items?calendar_api_id=<id>&period=future&pagination_limit=50`. No key needed. Notes:
  - The calendar is keyed by an opaque **`calendar_api_id`**, not the vanity slug — find it in the calendar page's embedded JSON. tiat's is `cal-twiOosdGMMY66DI`. The page embeds several: `cal-6Tci63IXSGPhZTU` (GenJam / Machine Cinema — a different org, and it lists LA events), `cal-a7fdlFz8rgkYA7t` (the Command Line Music series, hosted at 151 Powell but already re-listed in tiat's feed), and `cal-5atYDK12ADI1iCr` (no upcoming events). Only the first belongs to tiat.
  - `calendar/get?calendar_api_id=...` returns HTTP 400 — there's no working metadata call, so calendar names have to be inferred from the events themselves.
  - Response is `{entries, has_more, next_cursor}`; the event is at `entries[].event`. The sibling `entries[].calendar` is the calendar that **owns** the event, which differs from tiat's on this feed — tiat's calendar aggregates events owned by other calendars. Paginate with `&pagination_cursor=<next_cursor>`.
  - `get-items` returns **no description field**. Fixed for tiat (only ~4 upcoming events, so the cost is trivial): `fetchLuma()` now makes one extra `event/get?event_api_id=<id>` call per event when the calendar config sets `fetchDescriptions: true`, and flattens the rich-text `description_mirror` doc tree it returns into plain text — real copy, re-categorized against it. Not turned on for The Commons (~85 events) — that many extra requests per run isn't worth it for a calendar whose Community & Social fallback already lands right most of the time.
  - Times come back UTC in `start_at`; `url` is a bare slug (`https://luma.com/<url>`). Filter `location_type == "virtual"` — the tiat-adjacent calendars list online-only workshops.
- **Gather SF** — https://www.gathersf.org/events — a 501(c)3 teahouse/community nonprofit (tea, movement, mindful connection). Framer site; individual events are hosted on Luma. Currently "between homes" and running only occasional pop-ups, so the page is often sparse or shows stale past events (drop past events per global rules). Public Google Calendar ID `0cb73e0cfb94515e2121d1abb6489a84e79133780b7d7c1a5ebba0668340f9a9@group.calendar.google.com` (empty as of 2026-09-20). **Also ingested keylessly from the page** (`fetchGatherSF()`): the Framer page carries no JSON-LD of its own, but the Luma links in its HTML do — follow each one and read its schema.org `Event` block (`name`, `startDate`, `location.name`, `offers.price`). Same trick should work for any listing page that links out to Luma/Partiful/Eventbrite. Categorize on the title only; the Luma descriptions are long enough that keyword matching goes noisy. Category profile: Festivals & Markets, Community & Social, Fitness & Wellness (movement/qi gong). BONUS lead: the page also points to **Decentered Arts** (https://events.decentered.org) — a broad Bay Area art/community events list worth evaluating as its own source.
- **The Commons** — 540/550 Laguna St, Hayes Valley. A community/coworking space running a dense calendar of workshops, coaching sessions, socials, writing nights and the odd retreat. Events live on **Luma** (https://luma.com/thecommons), pulled the same way as tiat via `https://api.lu.ma/calendar/get-items?calendar_api_id=<id>&period=future&pagination_limit=50`. Calendar_api_id (from the page's embedded JSON, found the same way as tiat's): `cal-ahTi4ptrN9WCYkg`. Unlike tiat's, every entry on this feed is owned by The Commons' own calendar (no re-aggregation to filter out). Category profile: overwhelmingly Community & Social (coffee hours, public hours, socials), with a real slice of Talks & Workshops (coaching, AI/tech panels, SF Tech Week programming) and Fitness & Wellness (meditation, somatic healing, group bike rides) — `categorize()` falls back to Community & Social here. No description field from `get-items`, same tiat caveat, so events are categorized on title alone; unlike tiat, the per-event enrichment wasn't turned on here (see tiat's entry above) — this is the source where scraping real descriptions would move the needle most (cryptic titles like "LongeviTEA: A Tech Week Reset" or "Bonding with Bots" give the keyword matcher nothing to work with), but at ~85 events/run it's a heavier lift than tiat's 4.
- **Civic Joy Fund** — https://civicjoyfund.org/events — a 501(c)(3) (a program of the Civic Space Foundation) putting on free outdoor events across the whole city: roughly fifteen weekly neighborhood cleanups, monthly night markets (Chinatown, Sunset, Noe Valley, Excelsior, Visitacion Valley), street fairs, Sunday Streets, block parties, stairway walks. The widest geographic spread on this list — each event is somewhere different, so the venue has to come from the entry rather than the source. The events page itself carries **no event data at all**: it is a Squarespace page whose "Upcoming events" section is an Elfsight Event Calendar widget (`<div class="elfsight-app-<widget-id>">`), and that widget syncs a **public Google Calendar**. To re-derive the calendar ID: read the widget ID out of the page HTML, fetch `https://core.service.elfsight.com/p/boot/?w=<widget-id>` (no key), and look at `data.widgets.<widget-id>.data.settings.integrationGoogleCalendar.calendar.id` — currently `c_b0e78aa2d8125f99b281c06594c1e47e63f1bcb7c33e975f8b6d469204f6735f@group.calendar.google.com`, "Civic Joy Fund Events", America/Los_Angeles. Then ingest it like any other public calendar (Calendar API v3, `singleEvents=true`): 106 events in a 35-day window when this was written. Notes:
  - **Ignore the widget's own `settings.events`.** On a Google-backed widget that array is Elfsight's leftover demo content — a Los Angeles museum, lorem ipsum descriptions, dates in 2025 and 2030. None of it is real, and it is the first thing you hit in the JSON.
  - `location` is a full postal address, so the first comma-separated field is the venue ("Richmond Republic Draught House", "Portsmouth Square Park", "Leland Avenue & Peabody Street"). One entry in the current window has no location and falls back to the source name.
  - The link worth surfacing lives in an `<a href>` in the description — mobilize.us for the cleanups, Eventbrite / Luma / neighborhood sites for the rest (101 of 106 have one). `htmlLink` only opens the calendar entry, which is a dead end for RSVPing. Google rewrites some of those hrefs through `https://www.google.com/url?q=<real>`, so unwrap that and skip links that really are Google's (map pins).
  - No price field, and while the page bills these as free outdoor events a few link to ticketed Eventbrite walks, so `free` stays unknown.
  - **The calendar description itself is never real copy** — always a signup CTA ("Sign up here: <link>", "Details & RSVP"), so `categorize()` had nothing to read there and ran on the title alone. Titles turn out to be formulaic enough that this mostly doesn't matter (85 of 106 are "<Neighborhood> Clean[ ]Up", unambiguous on their own). `fetchGCal()` now tries to do better anyway: `enrichDescriptions: true` on this calendar's config fetches each event's own page and pulls a real description from its schema.org JSON-LD or `og:description`, then re-categorizes against it (`enrichDescription()`). Two things keep the cost down and the hit rate up: it skips mobilize.us and Google-redirect hosts outright (86 of 106 events — mobilize.us pages are signup forms, not descriptions, and page-scraping them wouldn't help anyway), and it fails silently (timeout, 403, no JSON-LD) back to the original boilerplate. In practice this reaches the ~15-20 events that link to Eventbrite or a one-off neighborhood site (night markets, festivals, walks) — real wins there: e.g. "Scaling the Heights: Telegraph Hill to Russian Hill" and "Truly Terrific: Tiled to Tiled Stairway Walk" only get tagged Fitness & Wellness once their scraped description mentions "walk," since neither title says so.
  - Category profile: Volunteering & Civic dominates (cleanups, park volunteering — ~85% of the calendar), then Festivals & Markets (night markets, street fairs) and a residual Community & Social for the handful description-scraping doesn't reach. Overlaps **Lower Haight Local**, which re-lists the weekly Lower Haight Cleanup at Tarragon Cafe — the dedupe catches it.

Pattern to reuse: many independent venues run on a headless CMS (Sanity, Contentful), host events on Luma/Eventbrite, publish an iCal feed, or expose a public Google Calendar — check for a JSON/API/calendar source before writing an HTML scraper (look at network requests or asset URLs for a project ID or calendar ID). A WordPress venue on The Events Calendar will answer `?ical=1` on its calendar page. For venues on DoTheBay/Do415, use the venue JSON feed (`/venues/<slug>.json`) — one parser covers all of them, but it only sees what someone cross-posted, so prefer the venue's own feed where there is one. Hand-scrape HTML only as a last resort. To add a venue: (1) check the venue's own site for a CMS/API/iCal/Google Calendar/Luma; (2) check `dothebay.com/venues/<slug>`; (3) fall back to HTML scraping.

## Tier 1 — structured feeds and APIs (build on these first)

- **Ticketmaster Discovery API** — free, ~5,000 calls/day. Search by geo/DMA (covers SF Bay Area) and by classification (Music, Arts & Theatre, Sports, Film, Miscellaneous). Backbone for ticketed music, theater, and sports, already categorized. https://developer.ticketmaster.com/products-and-docs/apis/discovery-api/v2/
- **SF Funcheap — RSS feed** — free/cheap events across every category, updated daily. https://sf.funcheap.com/rss-date/
- **SF Rec & Park — RSS + calendar** — city recreation, fitness, outdoor, community events. https://sfrecpark.org/rss.aspx
- **Songkick API** — concerts by metro area (SF Bay Area). Needs an API key. https://www.songkick.com/metro-areas/26330-us-sf-bay-area
- **Bandsintown API** — concert/tour data by artist and city.
- **Meetup (GraphQL API)** — fitness, running/cycling clubs, tech, social, hobby groups. Needs OAuth.
- **DataSF / SFGov** — city open-data and official civic events; permitted street events/festivals. https://sfgov.org/

## Tier 2 — scrape-friendly, well-structured sites (fill the gaps)

- **DoTheBay / Do415** — strong, category-tagged listings; `/venues/<slug>.json` and other JSON feeds are clean. https://dothebay.com/
- **19hz.info (Bay Area)** — the definitive list for electronic/dance/DJ events. Tabular and easy to parse.
- **Decentered Arts** — https://events.decentered.org — a large Bay Area art/community events list (surfaced via Gather SF). Evaluate for coverage and structure.
- **SF Station** — general calendar with category sub-calendars. https://www.sfstation.com/calendar
- **SF/Arts (sfarts.org)** — dedicated arts & culture calendar. https://www.sfarts.org/calendar/
- **AllEvents.in** — aggregates many sources. https://allevents.in/san-francisco/calendar
- **Eventbrite (scrape or org-only API)** — workshops, fitness classes, cultural/community events. Public search API is gone. https://www.eventbrite.com/d/ca--san-francisco/events/

## Tier 3 — editorial / curation (great for enrichment, harder to fully automate)

- **7x7** — arts & culture roundups. https://www.7x7.com/
- **Time Out San Francisco** — things-to-do editorial.
- **The Bold Italic** — local culture and events roundups.
- **48 Hills** and **Broke-Ass Stuart** — alt/underground culture and free events.
- **SF Chronicle Datebook** — arts and entertainment editorial calendar.

## Category → best sources

- **Music (ticketed + DJ/electronic):** Ticketmaster Discovery, Songkick, Bandsintown, 19hz.info, DoTheBay. **Free/small:** Funcheap, Sofar Sounds.
- **Arts / theater / museums:** Ticketmaster (Arts & Theatre), SF/Arts, venue sites (SFMOMA, de Young, Exploratorium After Dark, Cal Academy NightLife, SF Symphony/Opera/Ballet), 7x7.
- **Festivals & markets:** Funcheap, DoTheBay, DataSF, Lower Haight Local, Civic Joy Fund, SF Travel, neighborhood/cultural-district calendars.
- **Fitness & wellness / outdoors:** Meetup, SF Rec & Park, Lower Haight Local (line dancing), Gather SF (movement/qi gong), Eventbrite (fitness classes), Strava clubs, November Project SF.
- **Volunteering & civic:** Civic Joy Fund (neighborhood cleanups, park volunteering), DataSF, Rec & Park.
- **Talks & workshops:** The Commons (coaching, AI/tech panels), tiat (maker sessions, salons), Eventbrite, Meetup.
- **Community & social:** Lower Haight Local, Wave Collective, Gather SF, The Commons, Funcheap, Broke-Ass Stuart, 48 Hills, SF Public Library events.

## Recommended v1 build

Start with the pieces that need the least glue: **Ticketmaster Discovery API + Funcheap RSS + Rec & Park RSS + Meetup API + the tracked venues** (Faight CMS, Madrone via its own iCal export, Wave Collective + Lower Haight Local + Gather SF via Google Calendar API), then add scrapers for **DoTheBay** and **19hz.info** once the pipeline works. Apply the global normalization rules — especially dropping private and past events, sorting within each day by start time, and deduping across sources.
